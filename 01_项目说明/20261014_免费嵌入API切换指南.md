# 免费嵌入API切换指南

日期：2026-10-14。目标：将RAG嵌入从阿里云切换为硅基流动免费BAAI/bge-m3，对话生成继续使用已验证的DeepSeek；不自动选择收费Pro模型。

## 为什么选择它

硅基流动[官方价格页](https://www.siliconflow.cn/pricing)当前将BAAI/bge-m3标为免费，Pro/BAAI/bge-m3则收费。选择的是前者，不是依赖一次性赠送额度的收费型号。具体可用性与限流以账号控制台为准。

[BGE-M3官方模型卡](https://huggingface.co/BAAI/bge-m3)给出1024维、8192 Token及多语言支持；与现有VECTOR(1024)表匹配。[嵌入API文档](https://siliconflow.readme.io/reference/createembedding)的端点为https://api.siliconflow.cn/v1/embeddings，兼容现有OpenAI调用结构。

## 你需要完成的一步

1. 登录硅基流动控制台，在API密钥管理中创建自己的Key。
2. 打开项目根目录.tmp/phase4-embedding-provider.properties；文件已准备且被Git忽略。
3. 将siliconflow.api-key=not-configured中的not-configured替换为Key本身，不加引号；provider=siliconflow保持不变。不要把Key发到聊天或提交Git。
4. 回复“已配置，允许发送演示资料继续验证”。外发目的地是https://api.siliconflow.cn/v1/embeddings，内容仍是已登记的演示知识/问题；没有真实客户工单。

新API不能使用旧阿里云Key。此前的Arrearage表明账号计费状态异常，并不能证明本次测试已经花完¥10。已有费用账本包含保守预留，不是厂商实际扣费账单。

## 已完成的工程适配

- application-siliconflow.yml单独配置供应商，优先使用SILICONFLOW_API_KEY环境变量或上述本地文件，避免把阿里云Key发给新厂商。
- 固定维度API不发送可配置dimensions字段，但仍校验返回向量为1024维；兼容旧阿里云显式dimensions请求。
- 评估费用代理对嵌入只允许BAAI/bge-m3，拒绝Pro/BAAI/bge-m3；缓存按供应商与模型隔离。DeepSeek计费仍受原¥10总门禁限制。
- 评估前检查当前嵌入模型与开发校准报告一致，模型变更后不能复用旧阈值。
- 未删表/删开发卷、未覆盖原阿里云配置或密钥；新Key未到位时不会向新厂商发请求。

## 配置完成后的执行顺序

1. 一条真实嵌入连通性预检，核实维度1024及返回正常。
2. 在独立阶段四PG库重建32条切片向量。模型空间不同，即使维度相同也不能混用；已有索引编排会按model变化全量重算。
3. 用旧32题开发集重新核查阈值，记录新模型与索引哈希；不直接套用阿里云的0.66或本轮临时0.60。
4. 先重跑RAG30题与Agent知识检索相关题，保留阿里云欠费首轮报告。新报告用供应商/运行标签区分，禁止覆盖旧结果。
5. 作者复核参考标签与回答事实，再完成阶段四效果验收。模板标签仍是AI协助草稿，不是假签署人工标签。

## 普通应用启动

配置完成后，项目启动器可显式选择供应商：

```powershell
Set-Location 'D:\SmartTicket-AI'
& '.\06_项目源代码\ticket-service\start.ps1' -EmbeddingProvider siliconflow -Mode real-model -Offline
```

首次缺Maven缓存时去掉-Offline。普通启动不会自动刷新向量索引，保持index-on-startup=false；正式更新仍按独立评估流程操作。offline-demo继续关闭对话与嵌入调用。
