### 2. 下载安装包到项目目录

```powershell
$base='D:\SmartTicket-AI\09_项目依赖与资源\02_下载链接与校验\安装包'
New-Item -ItemType Directory -Force -Path "$base\JDK","$base\Maven","$base\API工具"

# JDK 17（Temurin）
winget download --id EclipseAdoptium.Temurin.17.JDK --exact `
  --accept-source-agreements --accept-package-agreements `
  --download-directory "$base\JDK" --disable-interactivity

# 免安装版 JDK 17（用于项目内自包含）
Invoke-WebRequest -Uri 'https://github.com/adoptium/temurin17-binaries/releases/download/jdk-17.0.20.1+1/OpenJDK17U-jdk_x64_windows_hotspot_17.0.20.1_1.zip' `
  -OutFile "$base\JDK\OpenJDK17U-jdk_x64_windows_hotspot_17.0.20.1_1.zip"

# Postman
winget download --id Postman.Postman --exact `
  --accept-source-agreements --accept-package-agreements `
  --download-directory "$base\API工具" --disable-interactivity

# Maven 3.9.16（官方源 + 官方校验文件）
Invoke-WebRequest -Uri 'https://dlcdn.apache.org/maven/maven-3/3.9.16/binaries/apache-maven-3.9.16-bin.zip' `
  -OutFile "$base\Maven\apache-maven-3.9.16-bin.zip"
Invoke-WebRequest -Uri 'https://downloads.apache.org/maven/maven-3/3.9.16/binaries/apache-maven-3.9.16-bin.zip.sha512' `
  -OutFile "$base\Maven\apache-maven-3.9.16-bin.zip.sha512"
```

### 3. 校验与解压

```powershell
# Maven SHA512 官方比对
$expected=((Get-Content "$base\Maven\apache-maven-3.9.16-bin.zip.sha512" -Raw).Trim().Split(' ')[0]).ToLower()
$actual=(Get-FileHash "$base\Maven\apache-maven-3.9.16-bin.zip" -Algorithm SHA512).Hash.ToLower()
$expected -eq $actual        # 输出 True

# 解压 Maven
Expand-Archive -Path "$base\Maven\apache-maven-3.9.16-bin.zip" -DestinationPath "$base\Maven" -Force

# 解压免安装版 JDK 17 到项目内
Add-Type -AssemblyName System.IO.Compression.FileSystem
[System.IO.Compression.ZipFile]::ExtractToDirectory(
  "$base\JDK\OpenJDK17U-jdk_x64_windows_hotspot_17.0.20.1_1.zip",
  "$base\JDK\jdk-17-runtime")

# 全部下载物 SHA256
Get-ChildItem -Path $base -Recurse -File | Where-Object { $_.Extension -in '.msi','.exe','.zip' } |
  ForEach-Object { (Get-FileHash $_.FullName -Algorithm SHA256).Hash }
```

## 问题记录

| 序号 | 问题 | 现象 |
|---|---|---|
| 1 | 本机无 `mvn` 命令 | `Get-Command mvn` 返回 MISSING |
| 2 | winget 无官方 Maven 包 | `winget search --id Apache.Maven --exact` 返回「找不到与输入条件匹配的程序包」 |
| 3 | Maven 首次执行报错 | `The JAVA_HOME environment variable is not defined correctly, this environment variable is needed to run this program.` |
| 4 | Docker CLI 无法连接引擎 | `failed to connect to the docker API at npipe:////./pipe/dockerDesktopLinuxEngine` |
| 5 | 用 Start-Service 启动 Docker 服务失败 | `Cannot open 'com.docker.service' service on computer '.'` |
| 6 | 本机全局 JDK 为 25 | `java -version` 输出 openjdk 25.0.2，`JAVA_HOME` 指向 `openjdk-25.0.2`，与项目要求的 17 不一致 |
| 7 | Maven 平台编码为 GBK | `mvn -v` 显示 `platform encoding: GBK` |

---

## 解决方式

| 序号 | 解决方式 |
|---|---|
| 1 | 改用 Apache 官方 `dlcdn` 地址手动下载 Maven 二进制包，解压到项目目录使用 |
| 2 | 同上，不依赖 winget 源 |
| 3 | 显式设置 `JAVA_HOME` 指向项目内 JDK 17 目录后再执行 Maven |
| 4 | 启动 `Docker Desktop.exe` 主程序，等待约 60 秒让引擎完成初始化 |
| 5 | 不再使用 `Start-Service`，统一通过 Docker Desktop 主程序启动引擎 |
| 6 | 在项目内维护免安装版 JDK 17，IDEA 中单独配置 Project SDK 与构建 JDK，不使用全局 JDK 25 |
| 7 | 记录待办：阶段1 在 `pom.xml` 中显式声明 `project.build.sourceEncoding=UTF-8` |
