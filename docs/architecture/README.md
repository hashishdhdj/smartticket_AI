# 架构与设计入口

系统采用模块化单体。组件边界见[架构图](../../10_面试与复盘/01_架构与设计/阶段四_架构与边界.md)，当前改进见[整改计划](../../01_项目说明/20261019_专家评价核查与修改执行计划.md)。

MySQL 保存工单、任务、建议、审计和确认操作；PostgreSQL 保存知识切片与向量，使用 pgvector 和 pg_trgm。两库独立管理；现阶段资源文件是知识种子，工单解决记录自动回流尚待实现。不能把当前分析 Outbox 说成已经实现跨库知识同步。

RRF 融合向量和关键词排名，当前平滑常数 k=60；关键词使用 word_similarity，属于 pg_trgm，并非 BM25。向量相似度和阈值不是答案正确概率。

数据库版本条件更新是并发写入的最后防线；消息发送确认和消费者确认覆盖不同阶段。生成模型只提供建议和工具调用请求，服务端负责权限、参数、次数、时限和最终写入。
