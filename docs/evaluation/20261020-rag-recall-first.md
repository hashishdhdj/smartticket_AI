## 当前处理流程

1. 检索相关资料，并保留真实来源。
2. 分数达到0.55时，将完整正文交给模型，由模型判断资料能否回答用户问题。
3. 资料充分时生成答案；资料没有所需事实时，模型可返回语义拒答。
4. 低于0.55、检索不可用、无资料、模型失败或输出格式错误时保留相应失败原因和来源。

默认值与应用配置同时更新。来源范围、模型语义拒答、JSON结构、权限、工具确认和预算约束继续生效。本次没有改变提示词，也没有把未写明的政策或功能加入知识库。
