# 一线经验图谱：AI合成开发素材

日期：2026-10-22。供[当前实施计划](../../01_项目说明/20261022_一线经验知识图谱与Agent检索增强_实施计划.md)使用。

本目录是AI编写的演示输入，不是真实客户记录、真实员工操作或程序执行报告。`staff_experience_seed.json`含12条案例、3个逻辑员工身份引用；不含Key或真实账号ID。`manifest.json`记录素材哈希与数据结构检查结果。

| 编号 | 场景 | 主要用途 |
|---|---|---|
| EXP01 | 演示账号忘记密码，原手机号可收短信 | 带前提和模拟范围的处理指引 |
| EXP02 | 演示账号更换手机号，原号停用 | 不套用不满足的前提 |
| EXP03 | PUT只改标题，需保留描述 | 全量更新规则与来源 |
| EXP04 | 旧expectedVersion引起409冲突 | 异常处理指引与停止条件 |
| EXP05 | Outbox已发送但分析未完成 | 投递与处理结果的区别 |
| EXP06 | 知识已审核但索引未完成 | 发布流程中的状态区别 |
| EXP07 | 知识撤回但PG删除延迟 | 可见性、清理与关系来源 |
| EXP08 | 有效凭据请求他人工单 | 知识不能改变对象权限 |
| EXP09 | 与EXP01完全相同的经验结构 | 精确去重、复用已有版本 |
| EXP10 | 同样忘记密码但手机号已停用 | 与EXP01文字近似、条件不同，不应自动合并 |
| EXP11 | 员工曾给出错误PUT建议，后来纠正 | 失败尝试与有效步骤分离、差异审核 |
| EXP12 | 要求保证具体退款到账时刻，资料不足 | 不编造、保留未核实状态 |

`experience_card`为拟议输入结构，`evidence_refs`指向已有项目依据。演示短信规则不是SmartTicket真实能力。`simulated_business_feedback`由AI预设，`expected_behavior`为开发契约，均不能代替`actual_runtime`。所有`actual_runtime`初始为NOT_RUN且ID为空。

结构检查发现11张唯一规范化经验卡，EXP01/EXP09内容哈希一致。这个结果只是素材一致性检查，不能据此宣称后端去重功能已实现；实际去重服务仍需代码、数据库与接口验证。

目前没有将本目录导入数据库或运行知识索引，也没有建立真实PG图谱、新增Agent图谱工具或执行DeepSeek评估。后续导入器使用本次随机隔离身份创建合成工单，并映射素材逻辑标识。实际运行报告写入单独文件，不覆盖冻结素材或把预期结果改成运行结果。

首批素材是已知开发/演示场景，不是独立盲测。后续效果评估需另建冻结题集，并避免把同一场景简单改写后当作独立题。
